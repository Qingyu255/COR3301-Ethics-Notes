# Ethics & Social Responsibility Study Hub

This repository is organized for studying rather than for chronological file storage. Start with the course overview, move into the relevant week's materials, and use the focused guides only when you need deeper revision or exam practice.

## Start here

1. [Weeks 1–5 course overview](<study-guides/course-overview-weeks-01-05.md>) — the main map of the course, theories, cases, and exam method.
2. [Navigating morality and ethics](<study-guides/theory-guides/navigating-morality-and-ethics.md>) — a practical framework for analyzing unfamiliar dilemmas.
3. Open the relevant weekly folder for its slides, transcript, and detailed notes.
4. Use the focused theory, case-study, and exam guides to repair specific weaknesses.

## Recommended revision routines

### First learning a week

```text
slides → weekly notes → transcript clarification → self-check questions
```

### Revising for an exam

```text
course overview → theory definition from memory → unfamiliar case application
→ counterargument → qualified conclusion → targeted correction
```

### Open-book exam preparation

Do not try to search every file during the examination. Know this repository's map beforehand:

- use the course overview for quick theory selection;
- use the focused guides for exact tests and common mistakes;
- use sample cases to remember answer structure, not to copy conclusions; and
- use weekly notes when the question resembles a lecture case.

## Source hierarchy

When materials differ, use this order:

1. **Lecture slides** for formal doctrine and assigned case content.
2. **Lecture transcripts** for lecturer emphasis, oral clarification, and exam advice.
3. **Study notes** for synthesis, worked applications, and additional explanations.

The transcripts are automatically generated and can contain errors. Unclear transcript wording should not override an unambiguous slide.

## File-organization conventions

- Keep raw slides and transcripts inside their weekly folders.
- Put new weekly notes in the corresponding `weekN/` folder.
- Put cross-week explanations in `study-guides/theory-guides/`.
- Put extended applications to one case in `study-guides/case-studies/`.
- Put short checklists and personal examination reminders in `study-guides/exam-prep/`.
- Keep apps, quizzes, and generated code in `study-tools/`, not among lecture notes.
- Use lowercase, descriptive filenames with hyphens for new files.
- Update this dashboard whenever a new week or major guide is added.
