## Source hierarchy

The notes use this order of authority:

1. **Lecture slides** for doctrines, terminology, and formal steps.
2. **Lecture transcripts** for the lecturer's emphasis, exam advice, and oral clarifications.
3. **Explanatory interpretation** for bridges, objections, and examples not expressly stated on a slide.

Because the transcripts were generated from automatic captions, unclear transcript wording should not override an unambiguous slide.

## Exam-use principle

Use the notes as a retrieval system rather than a script to reproduce wholesale:

```text
accurate doctrine
→ complete application to the stated facts
→ genuine counterargument
→ relevant limitation
→ supported conclusion
```

Do not paste a generic criticism or example into every answer. Select only what fits the issue and explain why it matters to those facts.
